# M-Spirit-Taekwondo-Academy

Official website for **M - Spirit Taekwondo Academy**, located in Electronic City, Bengaluru.

## ✨ Features
- **Clean, Modern Design**: Fast, responsive, mobile-first design with dark martial arts aesthetic.
- **Mobile-Optimized Action Bar**: Fixed bottom quick actions (Direct Call, WhatsApp, Free Trial) for smartphone visitors.
- **Programs & Filter**: Batches categorized for Little Tigers (Kids), Teens & Adults, Olympic Sparring, and Conditioning.
- **Interactive Timetable**: Structured weekday and weekend batch schedules.
- **Real Photo Gallery**: High-resolution gallery featuring authentic student training, pad drills, and conditioning sessions with fullscreen lightbox modal.
- **WhatsApp Integration**: Instant trial booking and direct messaging to the Head Master.
- **Zero Heavy Dependencies**: Built with pure semantic HTML5, modern vanilla CSS, and vanilla JavaScript.

## 🚀 Running Locally
You can open `index.html` directly in any web browser, or serve it using any local static web server:

```bash
# Using Python
python -m http.server 3000

# Using Node.js (npx)
npx serve .
```
